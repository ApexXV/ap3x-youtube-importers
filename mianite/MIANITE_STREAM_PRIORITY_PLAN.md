## Safety

The priority importer holds the channel and regular-playlist run locks for its whole run, plus a separate priority run lock. It takes the shared music importer lock around each scan/probe/download/promotion; it yields to the 03:30–05:30 New York music window and active artist service. It retains a 1 TiB media-array reserve. A fresh playlist scan must exactly match the 25 pinned IDs and title before downloads and again at the end. It probes access before any media download, rejects Shorts and live videos, uses the highest available `bv*+ba/b` format with a single serial yt-dlp process, preserves `.part` stages, stores only sanitized metadata, and stops on bot verification, HTTP 429, source drift, exhausted retries, or unavailable items. It does not start or stop another importer itself.

Each promotion writes a pending intent before hardlinking sidecars and media into Season 03, then writes a record with sizes and SHA-256 values after `ffprobe`. The `verify` action can check sizes or all hashes. `rollback --position N --confirm-rollback` removes only record-matching files created for one priority placement; the original CaptainSparklez files and edited Mianite seasons remain untouched. No priority media or service was deployed or started when this plan was written.
